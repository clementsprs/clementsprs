# Hi, I'm Clément

Marketing lead at [Claap](https://www.claap.io) (by [lemlist](https://www.lemlist.com)). Most of my marketing ships as software: games, AI agents and tools for sales teams, built with Claude Code.

## Things I've built

| Project | What it does |
|---|---|
| [Claap agent gallery](https://www.claap.io/agent-gallery) + [`claap-skills`](https://github.com/clementsprs/claap-skills) | Ready-to-run Claude agents that work on your real call recordings: win/loss, deal risk, battlecards, rep ramp drills. Install as a Claude Code plugin. |
| [Roast My Call](https://roast-my-call.vercel.app) | Paste a discovery call, pick a coach, get your call scored play by play. |
| [Better Cold Call](https://better-cold-call.vercel.app) | A 2-minute voice cold-call game against an AI prospect, with a live leaderboard. |
| [Make the Number](https://make-the-number.vercel.app) | Play a VP Sales quarter: pick your tools and plays, try to hit the number. |
| [Sales Invaders](https://sales-invaders.vercel.app) | Arcade game: clear the objections, close the quarter. |

## Install the Claap plugin

```
/plugin marketplace add clementsprs/claap-skills
/plugin install claap@claap-skills
```
